NES IDEassembler 6502 · emulatore integrato · un solo file





Premi RUN. Clicca lo schermo per giocare: frecce, Z = B, X = A, Invio = Start, Shift = Select.




Editor tile








Disegna con il mouse. Lo slot 0 è il colore di sfondo. Le modifiche entrano nel sorgente con «Applica al codice» o con RUN, e si vedono subito nel gioco in esecuzione.


Editor schermata






Modo tile: disegna con il tile scelto nell’editor tile. Modo colore: assegna la palette (0–3) a blocchi di 2×2 tile; i colori delle palette si cambiano nell’editor tile. Nel codice trovi le etichette screen e screen_pal da copiare nella PPU (vedi l’esempio «Schermata»).


Sprite composti e animazioni








Ogni cella è un tile 8×8; la cella con il bordo rosso è il punto di riferimento. Il tile e la palette (0–3) vengono dall’editor tile e da quello schermata. Nel codice trovi meta_0… e meta_table.


Musica (tracker)







Clicca una cella e suona con la tastiera: Z S X D C V G B H N J M = Do…Si (ottava a scelta), «,» = Do successivo, Spazio = fine nota, Canc = cancella, frecce per muoverti. Colonne: quadra 1, quadra 2, triangolo, rumore (per il rumore la nota sceglie il tipo, 1–16). Nel gioco: jsr music_init una volta e jsr music_update a ogni NMI.


Debugger





Premi RUN, poi metti in pausa per vedere registri, istruzioni e memoria.


Sintassi

Etichette nome: · costanti NOME=$2000 · .org .byte .word .res · #<x #>x byte basso/alto · .mirror v|h

Grafica: .chr N sceglie il tile N (0–255 tabella 0, 256–511 tabella 1), poi 8 righe .tile 01230123 (cifre 0–3 o .).

La ROM è NROM 32 KB PRG + 8 KB CHR ($8000–$FFFF): ricorda i vettori in .org $FFFA.
Mapper: .mapper 0|1|2|3|4 · .prgbanks N (16 KB) · .chrbanks N (8 KB) · .bank K sceglie il banco da scrivere a $8000; l’ultimo banco è fisso a $C000 (con MMC3 i banchi si scelgono in unità da 8 KB; .mapper 4).
Progetti: schede in alto (＋ nuovo, ✎ rinomina, ✕ elimina; ★ = file principale) · .include "file" · .macro nome a,b … .endmacro · .rept N · .if/.else/.endif · etichette locali @nome · 📦 ZIP salva tutto.




Guida rapida


Flusso: scrivi il codice a sinistra, premi RUN (F9). Gli editor di tile, schermate, sprite composti e musica scrivono nel sorgente quando premi «Applica al codice» o RUN.


Gioco: frecce, Z = B, X = A, Invio = Start, Shift = Select (clicca prima sullo schermo).


Assembler: .org .byte .word .res .mirror .mapper .prgbanks .chrbanks .bank .chr/.tile .include .macro/.endmacro .rept .if/.else/.endif, etichette locali @nome. I vettori vanno in .org $FFFA.


Progetti: schede in alto, ★ = file principale; 📦 ZIP salva tutto. Il pulsante «Trova in tutti» cerca in ogni file.


Messaggi: ✖ errori (cliccali per andare alla riga) e ⚠ avvisi (valori fuori da un byte, etichette mai usate).


Debug: pannello Debugger (passo, frame, breakpoint, memoria), palette, sprite e nametable. ⏪ riavvolge, 💾 salva lo stato.


Mapper: 0, 1, 2, 3, 4 (MMC3 con IRQ). NTSC/PAL dal menu. Il file README.md ha tutti i dettagli.
